Как это работает

Конвейер под маленькие модели: 1) модель пишет компактное ТЗ-реферат (SPEC.md), 2) в новой сессии строит план ровно из 3 частей — разметка + стили + весь JS одним файлом (меньше стыков — меньше ошибок), 3) каждая часть проверяется автоматически (синтаксис, id, дубликаты, вызовы функций), 4) максимум 2 раунда правок, затем перегенерация части с нуля; если и это не помогло — проект перезапускается с уроками в ТЗ.

1. Запустите сервер модели: builder\START_server.bat (или свой LLM на :8080).
2. Опишите задачу слева и нажмите «Создать».
3. Дальше — «Продолжить» с инструкциями, сколько нужно раз.
Результат: workspace/<проект>/dist/index.html
